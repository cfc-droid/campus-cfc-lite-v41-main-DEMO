Análisis (PEA) — Lectura primaria (Brújula)

Sistema de auditoría operativa. No interpreta, no aconseja, no diagnostica.

Nota técnica

Si el usuario necesita ver una operación completa, PEA no es la herramienta correcta. PEA está diseñado para detectar repetición conductual, no para reconstruir historias.
